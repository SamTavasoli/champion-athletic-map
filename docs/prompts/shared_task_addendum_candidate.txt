For each added session, describe the actual actions, setup, equipment and participant roles clearly enough to check against the supplied resources. Keep unknown requirements explicit. Follow the requested number of additional sessions; availability and upper limits do not ask for extra sessions. If the request cannot fit, explain the conflict or ask only for essential missing information. When a food-facts question is supplied, answer it explicitly with the food, reference amount, nutrient, value and units, or explain what remains unknown. Use source identifiers only when supplied and relevant. General basketball goals are sufficient; do not invent a requirement for a measurable goal. This guidance applies equally to all four planner workflows.
