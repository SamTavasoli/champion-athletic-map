# Development cases and weekly schedule checks

The Step 31-2 cell retains the original twenty drafts and earlier results.
Its private review records proposed categories, expected behaviour, source-bound
activity candidates, time-window proposals and unresolved feasibility conditions.
It is an assistant review under Sam's delegated authority, not a second human
review or acceptance of the final study population. All full feasibility
certificates remain pending. Private labels and witnesses are never public inputs.

The new version of each fictional profile adds schedule_coverage with the exact
planning-window dates and timezone. Its completeness flag is a new synthetic
authoring decision for nineteen cases; it is not inferred from an empty or
nonempty commitment list. The case with an unknown existing schedule retains
that unknown and has a false completeness flag. Existing fields are unchanged.
All four future pilot workflows must receive the identical amended public input
and common task addendum, including the nested drafting workflow in Version 4.
The original workflows are not activated or changed by this preparation cell.

The separate pilot_schedule checker composes the original checks in memory.
It can establish a weekly cap or rest-day pass only from explicit matching public
coverage and complete valid calendar/accounting/timing facts. Its pass proof
treats every calendar root as potentially relevant sport, regardless of its wording.
It retains the known lower-bound violations, existing check IDs, advisory rules,
and independent resource uncertainties. Missing coverage never becomes a pass.
The checker and schema are new versioned components; old results are not regraded.

Source-timing, partner layout, resource interpretation and independent scoring
still need review. A source citation alone does not prove a generated activity's
resource requirements, and an internal model evaluator is not final independent
scoring. A separately recorded, bounded operational probe may measure execution
with these limits. The representative pilot and final protocol remain unfinished.

This cell makes no HTTP, generation, retrieval-encoding or final-evaluation calls.
It saves a case-review package, explicit public amendment lineage and a summary.
Read results/step31_case_review_summary.json for the selected version and status.
