## Interpretation

The catalog reaches a larger *candidate* pool, not an approved pool. Matching a name or verifying a heading does not establish source accuracy of requirements, youth suitability, or permission to reproduce educational materials.

## Priorities before any publication or planner use

1. Complete source metadata checks and independently verify timing/equipment/participants for each candidate.
2. Resolve semantic duplicates and general warm-up scope, including previously flagged Quick Feet and Side Push.
3. Document permitted reuse rights or use independently authored drills and source links without copying proprietary instructions.
4. Add youth-specific suitability rules in Step 13 and independent coaching review as appropriate.
5. Run a release gate that prohibits unapproved candidates from retrieval or plan generation.
